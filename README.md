# Linux Permissions and Hardening Lab

## Project Overview

This project demonstrates basic Linux system security practices in a virtual machine.

## Objectives

* Practise Linux user and group management.
* Understand file permissions.
* Review firewall configuration.
* Review SSH security settings.
* Record commands and their results.

## Lab Environment

* Operating System: Linux (to be specified)
* Environment: Virtual Machine
* Tools: Linux Terminal

## Topics Covered

1. User and group management
2. File permissions using chmod and chown
3. Firewall configuration review
4. SSH security review
5. Lab report and command results

## Safety

All exercises are performed on my own virtual machine. Security settings are changed only when authorised.

## Conclusion

This lab helps develop practical knowledge of Linux permissions and basic system hardening
